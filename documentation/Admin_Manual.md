# Admin Manual

## Default Admin Credentials

```text
Email: admin@pillstream.com
Password: Admin@123
```

Change this password before production use.

## 1. How to Login as Admin

1. Open `http://localhost:5173/login`.
2. Enter admin email and password.
3. The system redirects to admin dashboard.

## 2. How to Open Dashboard

Click **Admin** in the navbar or open:

```text
/admin/dashboard
```

## 3. How to View Dashboard Statistics

Dashboard cards show:

- Total Users
- Total Products
- Total Categories
- Total Orders
- Total Sales
- Pending Orders
- Delivered Orders
- Low Stock Items

The dashboard also shows recent orders, monthly sales chart, and top products.

## 4. How to Manage Categories

1. Open **Categories** from admin sidebar.
2. Add category using the form.
3. Click **Edit** to update category.
4. Click **Delete** to remove/deactivate category.

## 5. How to Add Product

1. Open **Products**.
2. Click **Add Product**.
3. Fill product name, category, price, description, stock, dosage, pack size, manufacturer, expiry date, batch number, and flags.
4. Upload image if available.
5. Click **Save Product**.

## 6. How to Edit Product

1. Open **Products**.
2. Click **Edit** on any product.
3. Update product information.
4. Click **Update Product**.

## 7. How to Delete Product

1. Open **Products**.
2. Click **Delete**.
3. Confirm deletion.

## 8. How to Manage Users

1. Open **Users**.
2. Search users by name/email/phone.
3. Change role using role dropdown.
4. Delete users if needed.

## 9. How to View Orders

1. Open **Orders**.
2. Use filters to search by status/customer/order id.
3. Click **View** to open order details.

## 10. How to Update Order Status

1. Open **Orders** or order detail page.
2. Select a status: Pending, Approved, Packed, Dispatched, Delivered, or Cancelled.
3. Status updates immediately.

## 11. How to Update Payment Status

1. Open **Orders** or order detail page.
2. Select payment status: Pending, Paid, Failed, or Refunded.
3. Status updates immediately.

## 12. How to View Reports

1. Open **Reports**.
2. Select start date and end date if required.
3. Click **Apply**.
4. View sales summary, monthly chart, top products, and sales orders.
5. Click **Print** for browser print/export.

## 13. How to View Contact Messages

1. Open **Messages**.
2. Read customer messages.
3. Update message status to New, Read, or Replied.
4. Delete old messages if needed.

## 14. How to Logout

1. Click admin name in navbar.
2. Click **Logout**.

## Admin Responsibility Note

Admin must enter accurate medicine information. The system does not automatically recommend dosage or provide medical advice.
